# Публикация приложения и вставка в Tilda

## 1. Опубликовать app-сайт

Соберите статическую версию:

```bash
python3 export_static.py
```

Папка `docs/` готова для GitHub Pages. В настройках репозитория GitHub:

1. Settings -> Pages.
2. Source: Deploy from a branch.
3. Branch: `main`.
4. Folder: `/docs`.

Ожидаемый адрес приложения:

```text
https://drbenjaminbk-ai.github.io/georgian-web/
```

Для встраивания в Tilda используйте адрес с параметром:

```text
https://drbenjaminbk-ai.github.io/georgian-web/?embed=1
```

`embed=1` убирает лишний внешний фон и отступы, чтобы приложение аккуратно сидело внутри страницы Tilda.

## 2. Вставить в Tilda

В закрытой странице Tilda добавьте HTML-блок `T123` и вставьте код из файла:

```text
static/tilda-iframe-snippet.html
```

Если у приложения будет другой домен, замените:

```text
https://drbenjaminbk-ai.github.io/georgian-web/?embed=1
```

и origin в `allowedOrigins`.

## 3. Платный доступ

Быстрая схема:

1. В Tilda включить Members Area / Личный кабинет.
2. Создать закрытую страницу с тестами.
3. Вставить iframe-код на эту закрытую страницу.
4. Подключить оплату и выдавать доступ к группе пользователей после оплаты.

Такой вариант закрывает страницу Tilda. Для более строгой защиты нужно переносить приложение за backend-авторизацию: Tilda принимает оплату, а приложение проверяет токен/сессию перед загрузкой вопросов.

## 4. Проверка

После публикации проверьте:

- приложение открывается напрямую по GitHub Pages URL;
- Tilda-страница открывается только авторизованному пользователю;
- iframe меняет высоту при переходе между разделами;
- на телефоне нет двойного горизонтального скролла.
